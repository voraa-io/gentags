# Research statements

## Extraction

We need to demonstrate why extraction works because if extraction fails, representation is meaningless. Extraction is infrastructure, not the claim.

Extraction has to satisfy two properties:

1. It is feasible (models can produce gentags from text). (CHECKED)
2. It is recoverable across observers (not tied to a single model/prompt). (CHECKED)
3. It is evidence grounded (NOT CHECKED YET)

We do not need:
extraction accuracy
extraction optimality
extraction comparison to other extractors
information-theoretic compression analysis
Those would make extraction the main research topic, which it isn’t.
